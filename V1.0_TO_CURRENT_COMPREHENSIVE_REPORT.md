## 3. Family Authentication & Multi-Tenancy Architecture
* **Relational Database Schema Updates:**
  * `users`: Added `full_name`, `reset_token`, and `reset_token_expires`.
  * `household_members`: Maps multiple users to a shared `household_id` with role classification (`admin` vs `member`).
  * `household_invitations`: Tracks 7-day tokenized invitations (`invitation_id`, `household_id`, `email`, `name`, `token`, `status`, `expires_at`).
* **Cryptographic & Session Services (`app/services/auth.py`):**
  * Password hashing via `bcrypt` with automatic salting.
  * Persistent 30-day mobile sessions using HMAC-SHA256 JWT tokens (`pyjwt`).
  * Cryptographically secure URL-safe tokens (`secrets.token_urlsafe(32)`) for invitations and password recovery.
* **Authentication Endpoints (`app/routers/auth.py`):**
  * `POST /api/auth/register`: Family creation & primary user registration.
  * `POST /api/auth/login`: Authenticates with email and password.
  * `GET /api/auth/me`: Validates session tokens.
  * `GET /api/auth/family`: Fetches current family roster and pending invites.
  * `POST /api/auth/invite`: Dispatches spouse/member email invitation.
  * `GET /api/auth/invitation/{token}`: Validates invite links for arriving spouses.
  * `POST /api/auth/register-invited`: Spouse signs up and joins the existing family account.
  * `POST /api/auth/forgot-password`: Issues a 1-hour password reset link.
  * `POST /api/auth/reset-password`: Updates password via reset token.
